About this preview

This file is a visual preview of every LaunchHouse Events email template in the approved Operations Strip design system. Templates render with sample personalization values populated (e.g., Jordan for {{first_name}}) so each email displays as it would arrive in a real inbox.

Each template card shows the Slim or Premium Header, body, CTA treatment, signature variant (5-line standard or 3-line compact), and footer — assembled per the canonical specifications in 02_Email_HTML_Agent_Implementation_Brief.md and 06A_Operations_Strip_Email_Spec.md.

This is a preview for review purposes, not production-ready email HTML. Production email HTML must use table-based layouts with inline CSS, MSO conditional comments for Outlook bulletproof button rendering, and email-safe markup. This preview uses modern CSS for visual fidelity only. The CTO's implementation will produce email-safe HTML separately.
